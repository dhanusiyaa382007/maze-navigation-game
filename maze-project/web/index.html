Maze Navigation Game

A Data Structures in C project: mazes are generated and solved by a C program (stacks and queues), then played in the browser.

🎮 Play

Navigate 5 levels with arrow keys / WASD. Undo moves, ask for hints.

🔍 Solver

Watch BFS (queue) and DFS (stack) explore the maze step by step.

🏆 Scores

Your best moves and times per level.

📚 About

Data structures and algorithms used.
