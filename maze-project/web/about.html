About the Project

Data structures used

StructureWhere
Stack (array)Maze generation (recursive backtracker), DFS solver, rebuilding the shortest path, Undo in the game
Queue (linked list)BFS shortest-path solver
2D array + bitmaskMaze grid: each cell stores open passages N=1, E=2, S=4, W=8
Parent arrayBacktracking from goal to start to get the path

Complexity

Generation, BFS and DFS are all O(V + E) = O(w·h) for a w×h maze. BFS guarantees the shortest path; DFS may explore more cells.

How it fits together

c/maze.c generates 5 mazes and writes web/levels.js. The website pages read that file to play and visualize them.
